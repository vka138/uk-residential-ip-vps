## 线路与延迟：非大陆优化，建议中转

英国线路走 BGP 国际网络，没有做大陆直连优化。国内延迟的实测数据有两个口径：一份测评给出平均约 216ms，另一份第三方本地测试落在 240 到 280ms 区间，两者测量方式不同，你可以理解成 200ms 出头到 280ms 之间。

联通和部分地区移动直连速度尚可，电信用户延迟明显偏高。官方建议通过香港或日本节点中转，并在机器上开启 BBR 加速。养号、发视频、看流媒体这类对延迟不敏感的用途，直连加 BBR 可以接受；实时直播对稳定性要求高，中转节点基本是必配。

另外两个容易漏的细节：新机默认 SSH 端口是随机的，不是 22，登录前先去管理面板或开通邮件里核对；上传速度有波动，有测评反映电信和联通能跑满 300Mbps，移动上传不太稳定。想提前判断线路，可以用测评里给出的测试 IP 86.53.181.1 先 ping 一下路由。

发视频、养号、看流媒体对延迟不敏感，直连加 BBR 没问题。实时直播对延迟和稳定性要求高，电信宽带尤其明显，建议先配好香港或日本中转再开播。
